# eDiary 服务端

eDiary 的自托管日记同步服务，适合希望自行管理账号和日记数据的用户。

## 功能

- 提供账号注册、登录和会话管理。
- 管理日记本及条目，支持上传、下载和同步数据。
- 内置 Web 管理控制台，便于管理服务。
- 使用 SQLite 保存内部状态，支持持久化存储和日常备份。

## 安装

可在喵喵商店安装，也可以在本仓库 Releases 下载 `cloud.lazycat.app.ediary-server-v<版本>.lpk` 手动安装。`checksums.txt` 提供 SHA256 校验信息。

要求懒猫系统 1.5.0 或更新版本。

## 使用

安装后打开应用的 `/admin` 页面，完成首次管理员设置。日记数据保存在 `/lzcapp/var/ediary`，请定期备份。

在 eDiary 客户端中填写自己的服务地址后进行连接和同步。
